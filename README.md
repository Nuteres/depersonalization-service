Автономное кроссплатформенное настольное приложение для автоматического поиска, обезличивания и **обратного восстановления** персональных данных в электронных таблицах, текстовых документах и PDF в соответствии с требованиями Федерального закона № 152-ФЗ и Приказа Роскомнадзора от 19.06.2025 № 140.

---

## Скачивание и установка

Готовые исполняемые файлы для всех поддерживаемых платформ публикуются в разделе **[GitHub Releases](https://github.com/Nuteres/depersonalization-service/releases/latest)** (каталог `bin/` не хранится в git и формируется только при локальной сборке из исходников).

| Платформа | Архитектура и требования | Файл в Releases | Запуск |
|---|---|---|---|
| **macOS** | Apple Silicon M1–M4 + Intel, macOS 11+ | `Depersonalizer.app.zip` | Распаковать архив и перенести `Depersonalizer.app` в «Программы» |
| **macOS CLI** | Apple Silicon M1–M4 + Intel, macOS 11+ | `depersonalizer-darwin-universal` | `chmod +x depersonalizer-darwin-universal && ./depersonalizer-darwin-universal` |
| **Alt Linux** | Alt Linux 10.4 (p10), x86_64, glibc 2.32, GTK3 / WebKit2GTK | `depersonalizer-altlinux-amd64` | `chmod +x depersonalizer-altlinux-amd64 && ./depersonalizer-altlinux-amd64` |
| **Windows** | Windows 10 / 11 x86_64 (WebView2) | `depersonalizer-windows-amd64.exe` | Запустить двойным кликом |

> [!NOTE]
> Локальные сборки для macOS не подписаны сертификатом Apple Developer ID. При первом запуске `Depersonalizer.app` Gatekeeper может заблокировать открытие: откройте приложение через правую кнопку мыши → **«Открыть»** (или снимите карантин командой `xattr -cr /Applications/Depersonalizer.app`).

## Ключевые гарантии и возможности

- **100% Air-Gapped без сетевых соединений** — программа полностью автономна, не отправляет телеметрию, не обращается к внешним CDN и не требует доступа к интернету. Все операции выполняются на локальной рабочей станции.
- **Семантическая токенизация DLP-Safe** — персональные данные в таблицах и текстах заменяются на типизированные токены вида `[ФИО_0001]`, `[СНИЛС_0001]`, `[Паспорт_0001]`, `[Телефон_0001]`. Один и тот же субъект получает одинаковый токен на всех строках и листах документа, поэтому аналитические сервисы и облачные LLM (ChatGPT, Claude, Gemini) сохраняют связи между записями без утечки реальных данных и блокировок DLP.
- **Бескоординатное обратное восстановление** — зашифрованный ключ **`.depmap`** (AES-256-GCM + PBKDF2-HMAC-SHA256, 100 000 итераций, права `0600`) позволяет вернуть исходные ПДн даже после сортировки или перемешивания строк, переименования или перестановки столбцов, добавления новых аналитических колонок (`Score`, `Cluster`, `AI_Summary`) и включения токенов внутрь текстовых комментариев нейросетей.
- **Соответствие Приказу РКН № 140**:
  - криптостойкое перемешивание порядка строк таблиц (`crypto/rand`, алгоритм Фишера–Йетса, п. 13 Приказа № 140);
  - автоматический локальный журнал учёта операций `~/.depersonalizer/audit.jsonl` с контрольными суммами **SHA-256** исходных и итоговых файлов и выгрузкой в `.jsonl`.
- **Необратимое вымарывание PDF** — постраничный предпросмотр через автономный Mozilla PDF.js, точечное исключение отдельных вхождений кликом по плашке и физическое удаление текстовых операторов из контентных потоков с наложением векторных прямоугольников (`Blackout Redaction`).
- **Защищённые ZIP-архивы для пересылки** — опциональная упаковка очищенного документа в `.zip` с паролем (PKWARE ZipCrypto) для распаковки встроенными средствами Windows, macOS и Linux без сторонних архиваторов. Файл-ключ `.depmap` в архив не добавляется.

## Поддерживаемые форматы и категории ПДн

### Поддерживаемые форматы файлов

| Категория | Форматы | Особенности обработки |
|---|---|---|
| **Электронные таблицы** | `.xlsx`, `.xlsm`, `.xltx`, `.xltm`, `.xlsb`, `.xls`, `.ods`, `.xods`, `.csv`, `.tsv` | Многостраничные книги (Multi-Sheet); многоуровневые шапки и объединённые ячейки (`Merged Cells`) в `.xlsx`; `.xls`/`.xlsb` автоматически конвертируются в `.xlsx`; для `.ods`/`.xods` доступен выбор экспорта `.ods` или `.xlsx`; для `.csv`/`.tsv` — автоопределение разделителей `,` `;` `\t` `\|` и кодировок UTF-8, UTF-8 BOM, Windows-1251 |
| **Текстовые документы** | `.docx`, `.odt`, `.txt` | Предпросмотр в виде листа документа; преодоление фрагментации XML-тегов (run-splitting) в Word и ODT с сохранением шрифтов, отступов, списков и встроенных таблиц. *Устаревший бинарный формат `.doc` не поддерживается* |
| **Документы PDF** | `.pdf` | Ограничение размера до 100 МБ для безопасного рендеринга страниц; необратимое векторное вымарывание без создания `.depmap` |

### Автоматически распознаваемые категории ПДн

- **ФИО** (полные имена, инициалы, а также отдельные колонки «Фамилия», «Имя», «Отчество» и роли вроде «Участник», «Кандидат»; служебные поля подразделений, должностей и статусов отфильтровываются)
- **Паспорта РФ** (серия и номер, а также код подразделения в тексте)
- **СНИЛС** (валидация по контрольной сумме, модуль 101)
- **ИНН физических лиц** (проверка контрольных разрядов ФНС, защита от ложных срабатываний на словах вроде «инновация» и числовых баллах)
- **Номера телефонов** (мобильные и городские форматы РФ)
- **Электронная почта** (`email`)
- **Адреса** (регистрации, проживания, почтовые индексы и улицы)
- **Банковские карты и счета** (валидация алгоритмом Луна и BIN/IIN-префиксам, включая «МИР», а также 20-значные банковские счета в текстах)
- **Даты и временные метки** (даты рождения, выдачи документов, timestamp)
- **Табельные номера и грейды** (идентификаторы сотрудников и квалификационные разряды в таблицах)

## Инструкция по работе с программой

### 1. Обезличивание (Деперсонализация)

1. **Откройте файл**
   На вкладке **«Деперсонализация»** нажмите на область **«Выберите или перетащите файл»** или перетащите документ в окно программы. После анализа в верхней карточке появятся имя файла и кнопки **«Сменить»**, **«Удалить»**, **«Сохранить»**.

2. **Проверьте категории ПДн и предпросмотр**
   - В разделе **«Категории данных»** отобразятся найденные колонки (для таблиц) или типы сущностей (для документов). Кликните по карточке или переключателю, чтобы оставить поле без обезличивания (например, город или рабочий телефон).
   - **Для таблиц**:
     - если в книге несколько листов, переключайте их сверху — настройки отключённых колонок задаются для каждого листа отдельно (счётчик `-N` показывает число исключений);
     - отключать/включать защиту колонки можно также кликом по бейджу **`ПДн`** прямо в шапке таблицы;
     - переключатель **«Очищенные данные» / «Исходные с ПДн»** сравнивает результат с оригиналом, разделители в заголовках позволяют менять ширину столбцов, а кнопка **«Раскрыть»** открывает полноэкранный предпросмотр с подгрузкой строк по 50 записей (закрытие кнопкой **«Свернуть»** или `Esc`).
   - **Для Word, ODT и TXT**:
     - переключайте режим **«Очищенные данные» / «Исходные с ПДн»**;
     - наведите курсор на подсвеченную сущность для просмотра значений «До / После» и кликните по ней, чтобы отключить или снова включить обезличивание этой категории.
   - **Для PDF** *(до 100 МБ)*:
     - клик по отдельной плашке на странице снимает или возвращает скрытие именно **этого конкретного вхождения** (удобно, чтобы оставить реквизиты компании открытыми, скрыв ПДн клиента).

3. **Настройте параметры сохранения**
   Нажмите **«Сохранить»** — откроется окно **«Параметры сохранения»**:
   - **Формат сохранения** *(показывается для `.ods` / `.xods`)* — выберите `ODS` или `XLSX`. Старые форматы `.xls` и `.xlsb` автоматически конвертируются в `.xlsx`.
   - **Путь для сохранения файла** — оставьте поле пустым, чтобы файл автоматически сохранился рядом с исходным с суффиксом `_anonymized`, либо нажмите **«Обзор...»** для выбора другого каталога.
   - **Перемешать строки** *(только для таблиц, п. 13 Приказа РКН № 140)* — включает случайную перестановку строк. Данные внутри каждой строки остаются целыми и полностью восстанавливаются по ключу `.depmap`.
   - **Создать ключ деобезличивания** *(включено по умолчанию для всех форматов, кроме PDF)*:
     - задайте путь к файлу **`.depmap`** или оставьте сохранение по умолчанию рядом с итоговым файлом;
     - в поле **«Пароль ключа»** оставьте пустое значение для автоматической генерации надёжного **16-значного пароля**, либо введите свой пароль (минимум 12 символов: только латиница `A–Z`/`a–z`, заглавные и строчные буквы, цифры `0–9` и спецсимволы, без кириллицы и пробелов).
   - **Упаковать в ZIP-архив с паролем** *(опционально, для отправки по почте)*:
     - в архив помещается только очищенный документ (ключ `.depmap` в архив не включается);
     - введите пароль архива (от 4 печатных ASCII-символов без пробелов), нажмите **«Сгенерировать»** или оставьте поле пустым для автогенерации 16-символьного пароля.

4. **Запустите обработку и сохраните пароли**
   - Нажмите **«Начать обезличивание»**. При необходимости операцию можно прервать в любой момент кнопкой **«Отмена»** в окне прогресса — неполные файлы будут удалены автоматически.
   - По завершении откроется окно результатов: используйте кнопки **«Показать»** или **«Показать в папке»**, чтобы открыть созданные файлы, и кнопки **«Скопировать»**, чтобы сохранить сгенерированные пароли в корпоративный менеджер паролей.

> [!IMPORTANT]
> Передавайте внешним аналитикам и загружайте в нейросети **только обезличенный файл** (или ZIP-архив). Файл-ключ `.depmap` и пароль храните строго отдельно внутри защищённого контура организации.

### 2. Обратное восстановление (Деобезличивание)

> Восстановление поддерживается для файлов `.xlsx`, `.xlsm`, `.xlsb`, `.xls`, `.ods`, `.csv`, `.tsv`, `.docx`, `.odt`, `.txt`. Документы PDF вымарываются безвозвратно.

1. Перейдите на вкладку **«Восстановление»** (или перетащите файл **`.depmap`** в любое место окна — приложение переключится автоматически).
2. В карточке **«Файл данных»** выберите или перетащите документ, вернувшийся после анализа.
3. В карточке **«Ключ деобезличивания»** выберите соответствующий `.depmap` файл.
4. В карточке **«Пароль ключа»** введите пароль от ключа (при корректном пароле статус сменится на **«Готово к восстановлению»**).
5. Нажмите **«Восстановить данные»** (или `Enter` в поле пароля) и выберите место сохранения (по умолчанию предлагается `<имя>_restored.<расширение>` в папке файла данных).
6. Все токены `[Тип_ID]` вернутся к исходным ПДн, при этом новые добавленные аналитиками колонки, формулы, переименованные заголовки, изменённый порядок строк и токены внутри текстовых комментариев будут сохранены.

---

### 3. Журнал аудита и масштаб интерфейса

- **Журнал учёта операций (Приказ РКН № 140)**: нажмите кнопку **«Журнал»** в верхней панели, чтобы просмотреть последние 50 операций из `~/.depersonalizer/audit.jsonl` (время, тип операции, файл, количество записей, статус, SHA-256 хэши до и после обработки) и выгрузить полный реестр кнопкой **«Экспорт»** в файл `.jsonl`.
- **Масштаб интерфейса (UI Zoom, от 70% до 200%)**: регулируется кнопками `-`, `100%`, `+` в шапке окна, клавишами `Ctrl/Cmd + +`, `Ctrl/Cmd + -`, `Ctrl/Cmd + 0` (шаг 10%) и `Ctrl/Cmd + колёсико мыши` (шаг 5%). Выбранный масштаб запоминается автоматически.

> Подробное описание всех сценариев, криптографического контейнера и FAQ приведено в [Руководстве пользователя](docs/USER_GUIDE.md) и [Базе знаний](docs/KNOWLEDGE_BASE.md).

## Сборка из исходников

Для локальной сборки требуются **Go 1.25+**, **Node.js 18+**, компилятор C (для CGO на macOS/Linux) и Docker (для сборки под Alt Linux). Все внешние Go-зависимости завендорены в `vendor/` для полностью автономной сборки, а артефакты помещаются в локальный каталог `bin/`.

| Команда | Назначение |
|---|---|
| `make build-all` | Сборка бинарных файлов под все три платформы (Alt Linux, Windows, macOS) |
| `make build-macos` | Сборка Universal Binary (`arm64` + `amd64`) и бандла `bin/Depersonalizer.app` |
| `make build-windows` | Генерация PE-ресурсов `.syso` и кросс-компиляция `bin/depersonalizer-windows-amd64.exe` |
| `make build-altlinux` | Сборка в Docker-контейнере Alt Linux `alt:p10` в `bin/depersonalizer-altlinux-amd64` |
| `make build-frontend` | Сборка фронтенда Svelte 5 / Vite в `frontend/dist` |
| `make test` | Сборка фронтенда и запуск набора тестов Go |
| `go test -mod=vendor ./...` | Полный прогон Go-тестов с завендоренными зависимостями |
| `npm --prefix frontend run check` | Проверка типов TypeScript и Svelte |

## Структура проекта

```text
dep_service/
├── bin/                             # Локальные артефакты сборки (.gitignore; релизы публикуются в GitHub Releases)
├── build/                           # Конфигурации и утилиты сборки (Alt Linux Dockerfile, Windows .syso, macOS .app)
├── cmd/app/                         # Точка входа Wails v2 (main.go) и сквозные тесты
├── internal/
│   ├── domain/                      # Доменные модели и константы (FileInfo, ProcessOptions, лимиты)
│   ├── service/                     # Бизнес-логика (inspector, preview, processor, keymanager, restorer)
│   ├── desktop/                     # Адаптер Wails v2 (IPC-методы, события, системные диалоги)
│   └── version/                     # Единый источник правды для версии приложения (version.go)
├── pkg/
│   ├── anonymizer/                  # Семантическая токенизация (TokenSession) и генераторы ПДн
│   ├── audit/                       # Локальный журнал операций ~/.depersonalizer/audit.jsonl (SHA-256)
│   ├── depmap/                      # Криптоконтейнер .depmap (AES-256-GCM + PBKDF2-HMAC-SHA256 + политика паролей)
│   ├── detector/                    # Единый текстовый детектор ПДн, контрольные суммы (СНИЛС, ИНН, Лун)
│   ├── formats/                     # Обработчики XLSX/XLSB/XLS/ODS/CSV и DOCX/ODT/TXT/PDF + бескоординатное восстановление
│   └── ziputil/                     # Упаковка очищенных файлов в ZIP-архивы с паролем (PKWARE ZipCrypto)
├── frontend/                        # Интерфейс на Svelte 5 (Runes) + Vite 6 + Tailwind v4
├── tools/sync_kb/                   # Утилита синхронизации базы знаний FAQ (Notion + docs/KNOWLEDGE_BASE.md)
├── docs/                            # USER_GUIDE.md, ARCHITECTURE.md, KNOWLEDGE_BASE.md
├── vendor/                          # Полный комплект завендоренных Go-зависимостей (Air-Gapped)
├── Makefile
└── go.mod
```
