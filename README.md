Автономное кроссплатформенное приложение с графическим интерфейсом для автоматического поиска, деперсонализации и **обратного восстановления (деобезличивания)** персональных данных в таблицах (Excel, CSV) и документах (PDF) в соответствии с требованиями Федерального закона № 152-ФЗ «О персональных данных» и Приказа Роскомнадзора № 996.

---

## 📌 Ключевые возможности

- 🛡️ **100% On-Premise / Air-Gapped**: Данные не покидают рабочую станцию. Полное отсутствие внешних сетевых вызовов, трекеров, телеметрии и внешних CDN.
- 🔄 **Двусторонняя деперсонализация (Обратное восстановление)**:
  - Формирование зашифрованного файла-ключа **`.depmap`** при сохранении обработанного файла.
  - Возможность вернуть исходные ФИО, паспорта, СНИЛС после разметки подрядчиками или обработки в ML-моделях.
  - **Полное сохранение колонок подрядчиков**: новые столбцы (скоринг, сегменты, метрики), формулы и стили оформления остаются нетронутыми.
- 🔐 **Криптографическая стойкость ключа**:
  - Шифрование **AES-256-GCM (AEAD)** с защитой от модификации и подделки.
  - Формирование ключа через **PBKDF2-HMAC-SHA256 (100 000 итераций)** с уникальной солью (16 байт) и nonce (12 байт).
  - Поддержка пользовательского пароля либо встроенного мастер-ключа приложения.
  - Права доступа к файлу ключа на уровне ОС: `0600` (`-rw-------`).
- 🇷🇺 **Полный охват категорий ПДн РФ**:
  - **ФИО** с детекцией пола: мужские профили заменяются на реалистичные мужские, женские — на женские.
  - **СНИЛС** с расчётом валидной контрольной суммы по модулю 101.
  - **ИНН физических лиц** (12 знаков) с расчётом двух официальных контрольных сумм ФНС.
  - **Паспорта РФ** (4 цифры серии с кодом региона + 6 цифр номера).
  - **Номера телефонов** РФ (`+7 (9xx) xxx-xx-xx`).
  - **Банковские карты «МИР»** (префикс `2200` с валидным алгоритмом Луна).
  - **Даты рождения и выдачи документов** (сохранение года и реалистичный сдвиг $\pm N$ дней).
- 🔗 **Ссылочная целостность (Referential Integrity)**:
  - Детерминированная псевдонимизация на базе `HMAC-SHA256(значение, соль)`: одинаковые клиенты в разных строках и таблицах получают одинаковые синтетические значения.
- 📑 **Умный анализ таблиц**:
  - **Многостраничные книги Excel (Multi-Sheet)**: полноценная поддержка книг с несколькими листами: навигационные вкладки листов в основном интерфейсе и полноэкранном окне, раздельная настройка колонок по каждому листу, пакетное обезличивание всех листов в единый файл и сквозное восстановление через `.depmap`.
  - Автоматический поиск шапки таблицы при наличии пустых строк или преамбул выгрузки.
  - Автоматический расчет комфортной ширины столбцов под длину текста заголовков и бейджей `[ ПДн: Замена ]`.
  - Возможность выборочного отключения замены для любых колонок тумблером на карточке или кликом в шапке.
  - Интерактивное масштабирование ширины столбцов (вплоть до компактного вида с обрезкой текста `...`).
  - Полноэкранный предпросмотр с **динамической бесконечной подгрузкой строк** (порциями по 30 строк без нагрузки на память).
- ⬛ **Blackout Redaction для PDF**:
  - Физическое удаление символов из контентного потока PDF (текст невозможно скопировать или извлечь).
  - Наложение непрозрачных векторных рамок `[ ПДн СКРЫТО ]`.
- 🖱️ **Эргономичный UX**:
  - Умный Drag & Drop (перетаскивание `.depmap` автоматически активирует режим восстановления).
  - Живой прогресс-бар с замером времени и отображением обработанных строк/ячеек.
  - Быстрое копирование пути к ключу («📋 Копировать ключ») и переход к файлам в проводнике («📁 Показать в папке»).

## 🚀 Быстрый старт (Готовые бинарные файлы)

Готовые скомпилированные исполняемые файлы находятся в директории `bin/`:

### macOS (Universal: Apple Silicon M1-M4 + Intel x86_64)
```bash
./bin/depersonalizer
```
или запуск универсального бинарника:
```bash
./bin/depersonalizer-darwin-universal
```

### Alt Linux 10.4 (p10, x86_64, glibc 2.32)
```bash
./bin/depersonalizer-altlinux-amd64
```
*Собрано внутри сертифицированного окружения Alt Linux p10 с поддержкой WebKit2GTK и GTK3.*

### Windows 10 / 11 (x86_64)
Запустите двойным кликом:
```
bin/depersonalizer-windows-amd64.exe
```

## 📖 Сценарии использования

### 1. Деперсонализация файла для передачи подрядчикам
1. Откройте таблицу (`.xlsx` или `.csv`) через кнопку **«Открыть файл...»** или перетащите в окно.
2. Программа определит шапку и категории ПДн. Если какую-то колонку нужно оставить без изменений — отключите её тумблером на карточке.
3. Нажмите **«💾 Сохранить обработанный файл»**.
4. В окне сохранения оставьте активным чекбокс **«Создать защищенный ключ восстановления (.depmap)»** и при необходимости укажите пароль.
5. Нажмите «Выбрать путь и сохранить». Программа создаст очищенную таблицу и файл-ключ `.depmap`.
6. Очищенную таблицу можно безопасно передавать внешним аналитикам или подрядчикам.

### 2. Обратное восстановление данных (деобезличивание)
1. Переключитесь на вкладку **«○ Восстановление данных»** (или перетащите файл ключа `.depmap` в окно программы).
2. **Шаг 1**: Выберите возвращенный подрядчиками файл таблицы с новыми колонками (скоринг, сегменты, метрики).
3. **Шаг 2**: Выберите файл-ключ `.depmap`. Программа проверит целостность и покажет исходное имя файла и число записей.
4. **Шаг 3**: Введите пароль (если задавался при сохранении).
5. Нажмите **«🔓 Восстановить исходные данные...»**.
6. Исходные персональные данные вернутся на свои места, а добавленные подрядчиками столбцы и формулы сохранятся в полном объёме.

## 🛠️ Сборка из исходников

Для сборки требуются **Go 1.23+**, компилятор C (для сборки CGO под macOS/Linux) и Docker (для Alt Linux).

### Сборка под все платформы сразу:
```bash
make build-all
```

### Сборка под Alt Linux 10.4 (в нативном Docker alt:p10):
```bash
make build-altlinux
```

### Сборка под macOS Universal (ARM64 + Intel):
```bash
make build-macos
```

### Сборка под Windows (x86_64):
```bash
make build-windows
```

### Запуск тестов:
```bash
make test
```

## 📁 Структура проекта

```
dep_service/
├── bin/                             # Готовые бинарные файлы для всех ОС
│   ├── depersonalizer               # macOS Universal (симлинк)
│   ├── depersonalizer-darwin-universal
│   ├── depersonalizer-altlinux-amd64
│   └── depersonalizer-windows-amd64.exe
├── build/
│   └── altlinux/
│       └── Dockerfile               # Контейнер сборки под Alt Linux p10 (glibc 2.32)
├── cmd/
│   └── app/
│       ├── main.go                  # Точка входа Wails v2
│       ├── wails_app.go             # IPC-методы (ProcessFileTo, RestoreFileTo, InspectKeyFile)
│       └── wails_app_test.go        # Интеграционные тесты полного цикла
├── pkg/
│   ├── anonymizer/                  # Генераторы синтетических ПДн (ФИО, СНИЛС, ИНН, Карты, Паспорта)
│   ├── depmap/                      # Зашифрованный контейнер ключа .depmap (AES-256-GCM + PBKDF2)
│   ├── detector/                    # Валидаторы контрольных сумм и эвристический поиск шапки
│   └── formats/                     # Потоковые обработчики Excel, CSV и PDF Blackout Redaction
├── frontend/                        # Встраиваемый веб-интерфейс (//go:embed)
│   ├── index.html                   # Одностраничное приложение в стиле Notion / Linear
│   ├── assets.go                    # Go-пакет для встраивания ресурсов
│   └── tailwind.min.js              # Автономный локальный Tailwind CSS (без внешних CDN)
├── docs/
│   ├── USER_GUIDE.md                # Подробное пошаговое руководство пользователя
│   ├── ARCHITECTURE.md              # Техническая архитектура и спецификация протоколов
│   └── superpowers/                 # Архитектурные дизайн-документы и планы реализации
├── Makefile                         # Автоматизация кроссплатформенной сборки
└── go.mod
```
