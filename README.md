# Деперсонализатор ПДн (152-ФЗ РФ)

Автономное кроссплатформенное приложение с графическим интерфейсом для автоматического поиска и обезличивания персональных данных в файлах выгрузок (Excel, CSV, JSON) и документах (PDF).

## Ключевые особенности
- **100% On-Premise / Air-Gapped**: Данные не покидают периметр рабочей станции. Полное отсутствие внешних сетевых вызовов и телеметрии.
- **Соответствие 152-ФЗ**: Полный охват категорий ПДн РФ (ФИО с сохранением пола, СНИЛС по модулю 101, ИНН физлиц с двумя КС, Паспорта РФ с кодами подразделений, карты «МИР» с алгоритмом Луна, адреса, даты со сдвигом).
- **Сохранение связей**: Детерминированная псевдонимизация на базе `HMAC-SHA256(значение, соль)` — один и тот же клиент во всех связанных таблицах заменяется на одинаковый синтетический профиль.
- **Поддержка Alt Linux 10.4**: Нативная сборка в Docker-контейнере `alt:p10` против библиотек glibc 2.32 и WebKitGTK Alt Linux.
- **Однофайловый бинарник**: Автономный запуск в Alt Linux, Windows 10/11 и macOS.
- **PDF Redaction**: Физическое удаление текста из контентного потока PDF и наложение векторных непрозрачных черных рамок.

```

├── cmd/
│   └── app/                 # Точка входа приложения

├── build/
│   └── altlinux/

├── Makefile                 # Команды сборки для всех платформ

```

## Быстрый старт и сборка

### 1. Запуск интерфейса для разработки
Откройте файл `frontend/index.html` в браузере для предпросмотра интерфейса.

### 2. Сборка под Alt Linux 10.4 (в Docker)
```bash
make build-altlinux
```
На выходе формируется автономный бинарник `bin/depersonalizer-altlinux-amd64` и `.rpm`-пакет.

### 3. Сборка под Windows (x86_64)
```bash
make build-windows
```
Формирует портативный `bin/depersonalizer.exe`.

### 4. Сборка под macOS (Universal Binary)
```bash
make build-macos
```
Формирует `bin/Деперсонализатор.app`.
