Автономное кроссплатформенное приложение с графическим интерфейсом для автоматического поиска, деперсонализации и **обратного восстановления (деобезличивания)** персональных данных в электронных таблицах (`.xlsx`, `.xlsb`, `.xls`, `.ods`, `.xods`, `.csv`), текстовых документах (`.docx`, `.odt`, `.txt`) и файлах `.pdf` в соответствии с требованиями Федерального закона № 152-ФЗ «О персональных данных» и Приказа Роскомнадзора от 19.06.2025 № 140.

---

## 📌 Ключевые возможности

- 🛡️ **100% Air-Gapped безопасность**:
  - Полностью автономная работа в изолированном контуре без сетевых соединений, внешних CDN, сбора телеметрии или аналитики.
  - Обработка данных выполняется исключительно на локальной рабочей станции.
- 📋 **Соответствие нормативным требованиям РФ (152-ФЗ, Приказ РКН № 140)**:
  - Автоматическое ведение структурированного локального журнала операций `~/.depersonalizer/audit.jsonl` с расчетом хэшей SHA-256 исходных и сохраненных файлов.
  - Криптостойкое перемешивание порядка строк в электронных таблицах (п. 13 Приказа № 140) по алгоритму Фишера-Йетса для защиты от косвенной деанонимизации.
- 📊 **Поддержка 10 форматов документов**:
  - **Электронные таблицы**: Excel OpenXML (`.xlsx`), бинарный Excel (`.xlsb`, `.xls` BIFF8), OpenDocument (`.ods`, `.xods` «МойОфис», LibreOffice), текстовые таблицы (`.csv`, `.tsv`). Полноценная поддержка многостраничных книг (Multi-Sheet); сложных иерархических многоуровневых шапок и объединений ячеек (Merged Cells) в `.xlsx`.
  - **Текстовые документы**: Microsoft Word (`.docx`) и OpenDocument Text (`.odt`) с сохранением исходной верстки, шрифтов, стилей и структуры таблиц; простой текст (`.txt`).
  - **Документы PDF**: гарантированное физическое векторное вымарывание (Blackout Redaction) чувствительного текста из контентных потоков.
- ✂️ **Три стратегии обработки данных**:
  - **Для нейросетей (DLP-Safe, по умолчанию)**: замена чувствительных данных на семантические токены (`[ФИО_0001]`, `[СНИЛС_0001]`, `[Паспорт_0001]`), исключающие ложные срабатывания корпоративных DLP-систем при отправке файлов в облачные LLM.
  - **Синтетика**: генерация реалистичных данных с корректными контрольными суммами (СНИЛС, ИНН, карты «МИР») и сохранением ссылочной целостности через `HMAC-SHA256(значение, соль)`.
  - **Удаление**: гарантированная замена чувствительных фрагментов маркером `[УДАЛЕНО]`.
- 🔄 **Двусторонняя деперсонализация и бескоординатное восстановление**:
  - Генерация зашифрованного файла-ключа **`.depmap`** с шифрованием AES-256-GCM и PBKDF2-HMAC-SHA256 (100 000 итераций).
  - **Header-Aware механизм**: точное сопоставление колонок при обратном восстановлении даже при добавлении внешними аналитиками или LLM новых столбцов (`Score`, `Cluster`, `AI_Summary`).
  - Восстановление токенов из текстовых комментариев нейросетей и при перемешивании строк.
- 📦 **Защищённые паролем ZIP-архивы для email-отправки**:
  - Опциональная упаковка очищенного документа в защищённый паролем `.zip` архив (PKWARE ZipCrypto) для безопасной пересылки контрагентам с возможностью штатной распаковки в любой ОС без сторонних утилит.
  - Раздельное сохранение: архив и документ сохраняются отдельно от файла-ключа `.depmap`.
- 🔍 **Эргономичный интерфейс и интерактивный предпросмотр**:
  - Постраничный предпросмотр таблиц с динамической подгрузкой строк без перегрузки оперативной памяти.
  - Полностраничный предпросмотр документов PDF (Mozilla PDF.js) и Word с возможностью поточечного исключения сущностей из сокрытия.
  - Регулировка масштаба интерфейса (UI Zoom от 70% до 200%) с автосохранением.

## 🚀 Быстрый старт (Готовые исполняемые файлы)

Готовые бинарные файлы находятся в директории `bin/`:

### macOS (Universal: Apple Silicon M1–M4 + Intel x86_64)
```bash
./bin/depersonalizer
```
или запуск универсального бинарника:
```bash
./bin/depersonalizer-darwin-universal
```

### Alt Linux 10.4 (p10, x86_64, glibc 2.32)
```bash
./bin/depersonalizer-altlinux-amd64
```

### Windows 10 / 11 (x86_64)
Запустите файл двойным кликом:
```
bin/depersonalizer-windows-amd64.exe
```

## 📖 Сценарии использования

### 1. Деперсонализация (Обезличивание)
1. Откройте файл через кнопку **«Открыть файл...»** или перетащите его в окно программы.
2. Проверьте определенные категории ПДн и при необходимости отключите ненужные колонки.
3. Нажмите **«Сохранить...»** и выберите параметры сохранения (стратегию, пароль для ключа `.depmap`, перемешивание строк, создание ZIP-архива).
4. По умолчанию очищенный файл и ключ `.depmap` сохраняются рядом с исходным файлом (с суффиксом `_anonymized`).
5. Нажмите **«Начать обезличивание»**. Очищенный файл готов к безопасной передаче подрядчикам или загрузке в LLM.

### 2. Восстановление (Деобезличивание)
1. Перейдите на вкладку **«Восстановление данных»** (или перетащите файл `.depmap` в окно).
2. Выберите файл с возвращенными результатами, файл-ключ `.depmap` и введите пароль.
3. Нажмите **«Восстановить данные»**.
4. Программа вернет оригинальные персональные данные на свои места, сохранив все добавленные аналитиками новые столбцы и метрики.

> Подробные пошаговые инструкции и описание всех параметров приведены в [Руководстве пользователя](docs/USER_GUIDE.md).

## 🛠️ Сборка из исходников

Для сборки требуются **Go 1.25+**, **Node.js 18+** и компилятор C (для сборки CGO под macOS/Linux). Все Go-зависимости завендорены в каталоге `vendor/` (Air-Gapped).

Фронтенд автоматически компилируется через Vite при вызове команд `make`.

| Команда | Описание |
|---|---|
| `make build-all` | Сборка под все поддерживаемые платформы |
| `make build-macos` | Сборка универсального бандла macOS (ARM64 + Intel) |
| `make build-windows` | Кросс-компиляция для Windows (x86_64) |
| `make build-altlinux` | Сборка в сертифицированном Docker-контейнере Alt Linux p10 |
| `make test` | Запуск полного набора Go-тестов |
| `make build-frontend` | Сборка только бандла фронтенда |

## 📁 Структура проекта

```
dep_service/
├── bin/                             # Готовые бинарные файлы для всех ОС
│   ├── depersonalizer               # macOS Universal
│   ├── depersonalizer-altlinux-amd64# Alt Linux 10.4 (x86_64)
│   └── depersonalizer-windows-amd64.exe # Windows 10/11 (x86_64)
├── build/                           # Конфигурации и скрипты сборки (Alt Linux Dockerfile, syso)
├── cmd/app/                         # Точка входа Wails v2 (main.go) и сквозные тесты
├── internal/                        # Сервисный слой и адаптеры:
│   ├── domain/                      # Доменные модели (FileInfo, PreviewRow, результаты)
│   ├── service/                     # Бизнес-логика (inspector, preview, processor, keymanager, restorer)
│   └── desktop/                     # Тонкий адаптер Wails (IPC-методы, события, диалоги)
├── pkg/                             # Низкоуровневые модули:
│   ├── anonymizer/                  # Генераторы семантических токенов и синтетических ПДн
│   ├── audit/                       # Локальный журнал учета операций (Приказ РКН № 140, SHA-256)
│   ├── depmap/                      # Зашифрованный контейнер ключа .depmap (AES-256-GCM + PBKDF2)
│   ├── detector/                    # Валидаторы контрольных сумм и эвристический анализ
│   ├── formats/                     # Обработчики XLSX, XLSB, ODS, XLS, CSV, DOCX, ODT, PDF
│   └── ziputil/                     # Создание защищенных паролем ZIP-архивов
├── frontend/                        # Интерфейс на Svelte 5 + Vite + Tailwind v4
├── docs/                            # Документация проекта (USER_GUIDE.md, ARCHITECTURE.md)
├── vendor/                          # 100% завендоренные Go-зависимости (Air-Gapped)
├── Makefile                         # Автоматизация сборки и тестирования
└── go.mod
```
