# DLP-Safe Semantic Tokenization and Coordinate-Free Restoration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement DLP-safe semantic tokenization (`[ФИО_0001]`, `[Паспорт_0001]`, etc.) and a coordinate-independent reverse restoration engine that reliably restores sensitive personal data even when tables or documents have been shuffled, sorted, or enriched by LLMs and contractors.

**Architecture:** Token generator creates deterministic, typed tokens (`[Тип_XXXX]`) with an incremental counter and value cache, registering them in a zlib+AES-256-GCM encrypted `.depmap` key file. Format handlers replace PII with these tokens while keeping column headers intact. The restoration engine scans all cells and text nodes matching `Mapping[token]` (exact and bracketed substring matches), completely removing static `(sheet, header, row)` coordinates.

**Tech Stack:** Go 1.23, Wails v2, Svelte 5, Tailwind v4, Excelize v2, AES-256-GCM, PBKDF2-HMAC-SHA256.

**Spec:** [docs/superpowers/specs/2026-10-12-ai-safe-tokenization-and-restoration-design.md](file:///Users/nuter/Go/dep_service/docs/superpowers/specs/2026-10-12-ai-safe-tokenization-and-restoration-design.md)

## Global Constraints

- Go 1.23 with all dependencies vendored in `vendor/` (always build and test with `-mod=vendor`).
- 100% Air-Gapped: zero network calls, zero analytics, zero external CDNs.
- Cryptography: AES-256-GCM with PBKDF2-HMAC-SHA256 (100 000 iterations) for `.depmap`.
- Semantic Versioning: Single source of truth in `internal/version/version.go`, synced with `frontend/package.json` and `Makefile`. This release bumps version to `1.8.0`.
- Documentation: update `CHANGELOG.md` (Keep a Changelog), `docs/USER_GUIDE.md`, `docs/ARCHITECTURE.md`, `README.md`.
- Quality gates: `go test -mod=vendor ./...`, `npm --prefix frontend run check`, `npm --prefix frontend run build`, fresh binaries built into `bin/`.

## Review Focus

1. **Row shuffling and sorting by external LLMs:** Sorting by salary or alphabetical order must restore 100% of cells without corrupting row associations.
2. **Column reordering or insertion:** New calculation columns added by LLMs or contractors must not break restoration of adjacent token columns.
3. **Substring commentary generated by LLM:** An LLM producing textual summaries containing tokens (e.g., `«Премировать [ФИО_0001] на 50000 руб»`) must restore to `«Премировать Иванов Иван Иванович на 50000 руб»`.
4. **Zero DLP regex match:** Tokens must never match regular expressions for Russian passports (`\d{4}\s\d{6}`), SNILS (`\d{3}-\d{3}-\d{3}\s\d{2}`), or phones (`+7 9xx...`).
5. **No text corruption on non-token cells:** Bracketed regex substring matching must never alter words that are not present in `depmap.Mapping`.

	"regexp"

func TestTokenSession_GenerateToken_FormattingAndDLPImmunity(t *testing.T) {
	ts := NewTokenSession("test-salt")

	fio1 := ts.GenerateToken(TokenFIO, "Иванов Иван Иванович")
	fio2 := ts.GenerateToken(TokenFIO, "Иванов Иван Иванович")
	fio3 := ts.GenerateToken(TokenFIO, "Петров Петр Петрович")

	if fio1 != "[ФИО_0001]" {
		t.Fatalf("expected [ФИО_0001], got %s", fio1)
	}
	if fio2 != fio1 {
		t.Fatalf("expected deterministic token for identical original value, got %s != %s", fio2, fio1)
	}
	if fio3 != "[ФИО_0002]" {
		t.Fatalf("expected [ФИО_0002], got %s", fio3)
	}

	pass := ts.GenerateToken(TokenPassport, "4508 123456")
	if pass != "[Паспорт_0001]" {
		t.Fatalf("expected [Паспорт_0001], got %s", pass)
	}

	// Verify passport regex does NOT match token
	rePassport := regexp.MustCompile(`^\d{2}\s?\d{2}\s?\d{6}$`)
	if rePassport.MatchString(pass) {
		t.Fatalf("token %s must not match passport regex", pass)
	}

	// Verify phone regex does NOT match token
	phone := ts.GenerateToken(TokenPhone, "+7 916 123-45-67")
	rePhone := regexp.MustCompile(`^(\+7|8)\s?\(?9\d{2}\)?\s?\d{3}-?\d{2}-?\d{2}$`)
	if rePhone.MatchString(phone) {
		t.Fatalf("token %s must not match phone regex", phone)
	}

	if !IsBracketedToken(fio1) || !IsBracketedToken(pass) {
		t.Fatalf("expected IsBracketedToken to be true for tokens")
	}
	if IsBracketedToken("обычный текст") || IsBracketedToken("[Случайный текст с пробелом]") {
		t.Fatalf("expected IsBracketedToken to be false for non-tokens")
	}
}
