# Архив технических планов и спецификаций (docs/superpowers)

В данном каталоге собраны исторические проектные спецификации (`specs/`) и пошаговые планы реализации (`plans/`), созданные в процессе разработки отдельных подсистем приложения:

- **`specs/`**: архитектурные проектные документы отдельных итераций (дизайн обратной персонализации, расширение форматов, режим удаления, DLP-Safe токенизация, вымарывание в PDF, масштабирование интерфейса, защищенные ZIP-архивы и др.).
- **`plans/`**: хронологические планы задач и чек-листы выполнения соответствующих этапов.

> ℹ️ **Важное примечание о статусе документов**:
> Документы в данном каталоге являются **историческими артефактами разработки** и отражают состояние задач на момент их создания.
> 
> **Едиными источниками актуальной документации проекта являются**:
> 1. [Руководство пользователя](../USER_GUIDE.md) — актуальные пользовательские сценарии, форматы и функции.
> 2. [Архитектура системы](../ARCHITECTURE.md) — действующая техническая спецификация сервисов, криптографии и структур данных.
> 3. [Журнал изменений](../../CHANGELOG.md) — полная хронология версий и доработок.
> 4. [Регламент разработки для AI-ассистентов](../../AGENTS.md) — правила разработки, сборки и публикаций.
