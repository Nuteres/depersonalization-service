# Спецификация: Соответствие 152-ФЗ РФ и Приказу Роскомнадзора № 140 (Релиз 1.6.0)

## 1. Контекст и цели

Цель релиза 1.6.0 — приведение приложения деперсонализации данных в полное соответствие с актуальной нормативной базой РФ по защите персональных данных:
1. **Федеральный закон № 152-ФЗ «О персональных данных»** (с изм. ФЗ № 233-ФЗ от 08.08.2024, ст. 3 п. 9, ст. 6 п. 9, ст. 13.1, ст. 18 ч. 5, ст. 19).
2. **Приказ Роскомнадзора от 19.06.2025 № 140** (вступил в силу 1 сентября 2025 г., заменил отмененный Приказ № 996).
3. **Требования ФСТЭК России (Приказ № 21) и ФСБ России (Приказ № 378)** к техническим мерам и криптографической защите.

Ключевое требование к интерфейсу: **сохранение чистого, минималистичного стиля (Notion / Linear)** без лишних текстовых пояснений, нагромождений в скобках и визуального шума.

## 2. Архитектурные изменения

### 2.1. Криптографическая безопасность ключей `.depmap`
* **Проблема:** при сохранении без пароля файл шифровался статическим ключом `DefaultMasterSecret`.
* **Решение:**
  - Если пользователь не ввел пароль вручную, приложение автоматически генерирует криптографически стойкий случайный пароль (`crypto/rand`, 16 символов / 128 бит) для конкретного файла.
  - Сгенерированный пароль отображается в финальном окне успешного сохранения с кнопкой «Скопировать пароль».
  - Обратная совместимость: функция `LoadFile` сохраняет поддержку чтения ранее созданных файлов со старым мастер-секретом, но новые файлы больше никогда не шифруются публичным секретом.
  - В пакете `pkg/depmap` вводится интерфейс `CipherProvider` с текущей реализацией `AES256GCMProvider` и контрактом для подключения отечественных ГОСТ-алгоритмов.

### 2.2. Генерация криптографической соли по умолчанию
* **Проблема:** при отсутствии ввода использовалась константа `"152fz-secure-salt"`.
* **Решение:**
  - При открытии диалога сохранения соль всегда генерируется случайной функцией `GenerateSalt(16)` (32 hex-символа).
  - Поле соли в интерфейсе по-прежнему доступно для редактирования или перегенерации кнопкой со стрелками.

### 2.3. Модуль локального журнала учета операций (`pkg/audit`)
* **Требование Приказа РКН № 140:** оператор обязан вести учет всех действий по обезличиванию и операций с полученными данными.
* **Решение:**
  - Новый пакет `pkg/audit` и сервис `internal/service/audit`.
  - Запись ведется в локальный файл `audit.jsonl` в системной директории данных приложения (`~/.dep_service/audit.jsonl`).
  - Структура записи журнала:
    ```json
    {
      "timestamp": "2026-10-08T01:30:00Z",
      "user": "operator_username",
      "operation": "depersonalize",
      "source_file": "clients.xlsx",
      "source_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
      "records_count": 1420,
      "entities": ["FIO", "SNILS", "INN"],
      "result_file": "clients_anonymized.xlsx",
      "result_hash": "a1b2c3d4...",
      "key_created": true,
      "key_file": "clients_anonymized.depmap",
      "status": "success"
    }
    ```
  - В шапку приложения добавляется лаконичная кнопка «Журнал» (или вызов окна просмотра последних операций и выгрузки журнала в формате `.jsonl`).

### 2.4. Методы обезличивания: перемешивание и огрубление
* **Перемешивание порядка строк (Shuffling):** опциональный переключатель в диалоге сохранения (по умолчанию отключен, чтобы сохранять порядок строк для пользователей, которым важна структура).
* **Сдвиг и генерализация дат:** сохранение детерминированного сдвига с реалистичным интервалом, поддержка обобщения.

## 3. UI/UX требования
* Минималистичный и чистый интерфейс в стилистике Notion/Linear.
* Никаких длинных юридических справок или текста в скобках на основных экранах.
* В диалоге сохранения:
  - Формат экспорта
  - Соль (сгенерирована случайно, кнопка «Обновить»)
  - Чекбокс создания ключа
  - Поле пароля ключа (с подсказкой: «Если оставить пустым — сгенерируется автоматически»)
  - Чекбокс «Перемешать порядок строк»
* В окне успешного сохранения:
  - Ссылки на сохраненный файл и ключ
  - Если пароль был сгенерирован автоматически — лаконичный блок: «Пароль ключа: `******` [Скопировать]».
